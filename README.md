# my-bank-app
Микросервисное приложение «Банк» с использованием Spring Boot и паттернов микросервисной архитектуры.

# Запуск приложения
# Consul
Откройте командную строку (CMD) или PowerShell с правами администратора.
Перейдите в директорию, куда вы скачали бинарный файл:
bash
cd C:\bin\consul_1.22.1_windows_amd64
Use code with caution.

Запустите агент Consul в режиме разработки с включенным веб-интерфейсом (UI) с помощью следующей команды:
bash
consul agent -dev -ui
Use code with caution.

Флаг -dev запускает Consul в режиме разработки, который идеально подходит для локального тестирования и не требует сложной настройки.
Флаг -ui активирует веб-интерфейс, который будет доступен по адресу http://localhost:8500/ui.
Оставьте это окно терминала открытым. Агент Consul будет выводить логи в это окно и будет работать до тех пор, пока окно не будет закрыто.
